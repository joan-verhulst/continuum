# Patterns

A common need, and the parts it is built from and how they sit. Each row names the parts (`components.md`), the
placement (`pages.md`) and the values that matter; the medium files say how to write them. Where a need is
not here, build it by the recipe in `method.md` from the nearest row.

| Need                       | Build it as                                                                                                   |
| -------------------------- | ------------------------------------------------------------------------------------------------------------- |
| **List of objects**        | A ruled table in its frame: head 41 on the `neutral-100` fill, rows 41 with a hairline between, 12 padding; the first column the name (13 medium `neutral-900`), meta columns `neutral-700`, numbers tabular right, status a badge, people a 24 avatar and name, the last column (44) a ghost ellipsis for the row's menu. Group rows (34, muted, full width) for sections. A row opens the object's own page. |
| **Views of a list**        | Status views (All · Drafts · Published) with their counts in the dock at the panel's foot, beside the dock action for the page's primary. Never tabs above the table. |
| **Filters**                | Row 1, the toolbar, never moving: search (34, 256 wide), then a segmented control for one-of-few, a 34 select per value, or a Filter button (secondary, a filter icon, a count once applied) opening grouped checkbox values with "Clear all" at its foot. Row 2, only when filters apply, 8 below: a soft chip per group (25 high, pill, the `neutral-100` fill, no border, 13 `neutral-600`, a 12 × at the end: "Status is Paid or Overdue"), wrapping, then a ghost "Clear all". |
| **Selection of rows**      | A checkbox column (20 boxes; the head's box mixed when some are selected); selected rows on the 7% wash; a floating toolbar (38, `control` corners) at the foot with the count and the bulk actions, taking the dock's place while anything is selected. |
| **Inline add**             | A last table row holding a ghost button with a plus ("Add line"), its padding pulled so the label aligns with the first column's text. |
| **Totals under lines**     | A footer in the same table, each sum in the column of the amounts it totals: a slim head row (the `neutral-100` fill, 8 vertical padding) naming those columns, then a row per sum on the surface with no rules between (the label in `neutral-700`, 16 in from the edge), the total last with a hairline above it and 12 / 16 padding. Never a grey block, never a card beside the table. |
| **Editable cells**         | The table reads as values; a cell becomes editable on click: the value in a borderless 13 input on the tint wash, a select for a rate (the value and a small chevron). The row keeps its 41. |
| **Status / workflow**      | A soft badge (22, the ramp's 500 at 20% with 700 text, 11 medium, an icon at 12): draft `neutral`, waiting on someone `warning`, scheduled or informational `primary`, done `success`, failed `error`. Never a coloured row. |
| **Key figures (KPIs)**     | Stat cards in a row, 16 apart: 16 padding; a 13 regular `neutral-600` label, the value 18 medium `neutral-950` 4 below, a delta pill (22, success or error, neutral when flat) 12 below. Nothing inline after the value; a secondary figure ("of 418") is the label's business or a line in `neutral-600` under the value. A chart's headline is never also a stat card. |
| **The figure that leads**  | A chart card: 20 padding, 48 under the chart for its x labels, 32 between header and chart; the header a 13 `neutral-600` label, a 24 medium figure and its delta on one baseline; a legend only when two series need naming, as 11 labels with 8 colour dots at the header's right. |
| **Ranked breakdown**       | A bar list (top pages, sources, countries), its anatomy as in `components.md`; it collapses to "Show N more"; rows may be filter toggles. |
| **Key–value facts**        | A description list, or in a card a grid of label-over-value pairs three across (24 between columns, 20 between rows; the label 13 `neutral-600`, the value 13 medium 6 below). Icon-led facts (location, device) as a wrapping row of 16 icons with text. A read-only value (an ID, an API key) as a value field with a copy action. |
| **Timeline / history**     | An activity list in a sheet, its anatomy as in `components.md`: an icon tile per item, the title over its time. |
| **Steps of a run / a log** | A bordered list (card corners) of rows 41 or more, divided by hairlines, each with the same lanes left to right: a step number (13 `neutral-600`, 24 wide), an icon tile (32), the text (what happened, 13 medium, with the tool or object as a mono chip, and one line of result in `neutral-600`), the duration right in `neutral-600`, a badge only when the step is exceptional (retried, approved, failed), a chevron to open it. An open row takes the 3% wash and shows its detail below the text: attempts as a small list with times, input and output as code blocks (11 mono on the `neutral-100` fill, chip corners, 12 padding), side by side at 896. Normal steps carry no badge. |
| **Schedule / planner grid** | A bordered grid (card corners): the first column the resource (name 13 medium over a meta line, 56 rows when two lines), then a column per day with the day as a 41 head on the `neutral-100` fill, today's column on the 3% wash; hairlines between rows and columns (the one grid that divides both ways). Items in a cell are small blocks (item corners, the surface, a hairline, 8 padding): a 6 status dot, the task 13 medium, the time and person 11 `neutral-600`. A footer row of meters for capacity. |
| **Empty state**            | A left-aligned dashed panel (`panel` corners, 20; a dashed hairline): an optional icon tile, what goes here (13 medium), one sentence (13 `neutral-600`), one secondary button. No illustrations. A filter that matched nothing offers to clear it. |
| **Loading**                | Skeleton blocks and lines at the real element's size, the region marked busy. No spinner over a page; a spinner only inside the button that is busy. |
| **Search**                 | A small input (34) with a leading search icon and a trailing kbd (⌘K), level with the buttons beside it. |
| **Command palette**        | A dialog pinned near the top with a borderless search, groups of 36 rows that hide when they do not match, the recent records first, then places, then actions, each with its kbd or a quiet hint. |
| **Create or edit**         | The create or edit page kind: fields stacked at 640, sections 40 apart, the primary at the end. A short form (two or three fields) is a 480 dialog instead. |
| **Long form / wizard**     | A stepper over the form (horizontal above, or vertical beside a long one), the current step's fields under it, Back and Continue at the end; done steps can be returned to; a step with errors is marked and says what is missing. |
| **Settings**               | The settings page kind: one card per group, rows divided by hairlines, one switch or picker per setting, a dependent setting sharing its parent's space between hairlines (or under an eyebrow), the areas in the dock. |
| **Choice with explanation** | An option list: rows with a label over a description and a radio or checkbox in the trailing slot, 16 apart, each a hairline row when there are more than three. |
| **A single toggle with consequences** | A setting row with a switch, its description saying what turns on; a confirmation dialog only when it cannot be undone. |
| **Save state**             | A notice in the header bar: "Saving…" with a small spinner, then "Saved", sliding out from under the bar and leaving by itself. The same for small actions without undo ("Link copied"). |
| **Feedback after an action** | A toast: a 360 card at the bottom right, 24 from the edges, with Undo for anything reversible (the spec is in `components.md`). A message that must stay is an alert in the page (a bordered row with an icon, 13, in the status tone). |
| **Destructive action**     | In a row's menu, last after a full-width hairline, in `error-600`; confirmed in a 480 dialog whose primary is labelled with the verb ("Delete page"). |
| **Explaining a heading**   | An info tip (a 16 icon that opens a short popover) beside the title; never a paragraph of help text under it. |
| **Onboarding**             | A checklist card on the overview: the count and a bar, done steps ticked, the next one open with its action and a ghost Skip. |
| **An object's properties** | A facet of its own: the Settings view in the object's dock or tabs, its fields stacked at 640. Never a fixed column beside the object. |
| **Live state**             | A status dot (pulsing when live) beside the thing it describes; a live count as a figure with a dot ("129 Active now"). |
| **Usage / credits**        | A meter with a label and a caption ("4 of 5", "Resets in 10 days"); progress only for a task that finishes. A tone only when the amount warrants it (near the limit `warning`, over it `error`). |
| **Date / date range**      | A date picker in a form (38, a calendar icon); a date-range picker with its presets (Last 7 days, Last 90 days) for filtering a report or overview; a calendar inline only when the month itself is the content. |
| **Sign-in code**           | A code input (large when it is the page's only task), a resend ghost button, the error in the field's helper line. |
| **Drop zone / upload**     | A dashed well (item corners) with a line on what goes here and a secondary "Choose files"; on drag-over the dash darkens and the 3% wash fills it; the files follow as rows with a bar while uploading. |
| **Media grid**             | Tiles four across, 12 apart: item corners, a hairline, a 4:3 thumbnail on the 4% wash, then the name 13 medium and the meta 11 `neutral-600` in 10 padding. Selected: the 2px action outline, 2 outside. |
| **Board / kanban**         | Columns on the `neutral-100` fill (card corners, 8 padding, 8 between cards) with a header (title and count badge); cards the surface with item corners, a hairline, 12 padding; the `float` shadow only while dragging. |
| **Document / rich text**   | No box around the writing: the text sits on the panel at 14–16 with relaxed leading in `neutral-900`, 680 wide; headings medium at 24 / 18 / 16; a floating toolbar over the selection; blocks get a ghost grip handle on hover in the left margin. |
| **Chat / support**         | A thread of messages (own on the tint wash, right, at most 2/3 wide; others on the surface with a hairline, left), system lines as quiet events, tickets and invoices as mono tokens or linked reference rows, the composer at the foot (48 box, growing, 24 above the page's foot). |
| **Someone else is typing** | The typing row just above the composer, in its slot (faces and a dots pill, 24, 8 clear of the box, held while nobody types, so the box never moves), kept mounted and given the names; never in the thread, a toast or a status line in the header. |
| **Attach or link something to a message** | The composer’s filled "+" opens the picker, or, when more than files can go, a menu above it (16 icon and label per row: Add attachments, Link invoice, Link application). What is picked waits in a row 8 above the box, never inside it: a file as a tinted 32 well with name and extension, an image as a 40 thumbnail, a linked record as a full-width line (icon, kind, token, status badge), each with a remove ×; once sent, files hang 4 under the message on its side and records follow as reference rows. Never a separate upload field or a dialog. |
| **Reference a record by #** | Typing "#" (or "@" for people) in the composer opens suggestions in a panel 8 above the box, its full width: a title and rows (16 icon, the token, the owner in `neutral-600`); the arrows move, Enter picks and puts the token in the text, Escape closes. In the sent message the token is a mono chip. Never a separate search field. |
| **Ask an AI / an agent page** | The assistant page kind: empty, a large prompt (104, a 720 column) with the recent chats under it (rows 32, title left, age right in `neutral-600`, a primary dot when unread, no rules); once asked, the thread in that column and the prompt docked at the foot (72), its send a round 28 button in the action colour that becomes Stop while the reply streams; what is attached to a question waits inside the prompt's box, above the text. |
| **A conversation loading** | The thread's own skeleton message rows at its foot, never a centred spinner; earlier history: the spinner row at the thread's head. |
| **An assistant thinking or streaming** | A pending message from the assistant (the typing dots in place of or after its words), not a separate spinner. |
| **A message that failed to send** | "Not sent · Retry" in its meta line, not a toast. |
| **New messages while scrolled back** | The jump-to-latest pill with the count; when the thread opens, an unread divider above the first unseen message. |
| **Tree / hierarchy**       | Nav groups with inset items; each deeper level indents another 32. |
| **Workspace / project switch** | A sidebar switcher under the sidebar's header (or the footer account made one): the current one's 28 mark, name over a quiet line, a menu of the others with a check on the current, then "All …" and "New …". A breadcrumb menu only for siblings deeper in the trail. |
| **View switch**            | A segmented control (34 track, 29 items) for List · Grid or Draft · Preview; tabs only for the facets of one object on its detail page. |
| **A page on a phone**      | The same page, narrowed by the shell (`pages.md`, On a narrow screen): the sidebar a drawer behind the sidebar's own toggle at the header bar's far left (one toggle, never two), the panel inset and rounded as on a desktop, the column 16 in and 40 down. A row of controls scrolls (tabs, the dock, a toolbar, the table), hides (header actions, secondary actions, the results line, counts, optional columns) or stacks (the page head, stat cards two across, card pairs one column, facts two across); it never wraps, and nothing goes into a "⋯" menu. Fold only what cannot go: pagination to ‹ 3 of 25 ›, a segmented control of more than four options to a select, an index's selects into its Filter button. No rail. |
