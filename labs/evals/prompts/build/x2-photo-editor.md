# Photo editor (the main window)

The product is **Lumen**, a desktop photo editor for professionals. The screen is the whole app window with one
document open. The image is the work: everything else serves it.

**Menu bar**: File, Edit, Image, Layer, Select, Filter, View, Window, Help.

**Options bar** for the current tool (Brush): size 24 px, hardness 80%, opacity 100%, flow 100%, smoothing 10%.

**Tool rail** (icons, each with a tooltip; Brush is active): Move, Marquee, Lasso, Crop, Eyedropper, Brush,
Eraser, Gradient, Type, Shape, Hand, Zoom. Below them, the foreground and background colour swatches (black and
white).

**Document tabs**: "harbour-sunset.jpg @ 66.7%" (active), "logo-draft.png @ 100%".

**Canvas**: the image (no network: draw a placeholder, for example a warm gradient landscape rectangle in 4:3)
centred at 66.7% on the canvas background, with rulers along the top and left.

**Right panels**, stacked:

1. **Properties** (of the document): W 4032 px, H 3024 px, Resolution 300 ppi, Mode RGB, 8 bit.
2. **Adjustments**: Brightness/Contrast, Levels, Curves, Exposure, Hue/Saturation, Black & White (as icon
   buttons with tooltips).
3. **Layers**: blend mode Normal, Opacity 100%, Fill 100%. The layers, top first: "Text: Harbour at dusk"
   (type layer), "Curves 1" (adjustment layer, selected), "Sky replacement" (hidden), "Background" (locked).
   At the panel's foot: new layer, new group, add mask, delete.
4. **History**: Open, Crop, Curves 1, Brush tool, Brush tool, Brush tool (the last is current).

**Status bar**: 66.67% · 4032 × 3024 px · 300 ppi · sRGB IEC61966-2.1.
